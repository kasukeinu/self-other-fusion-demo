## 1. 目的と位置づけ

自分の手のライブ映像と比較対象の映像を一定周期で切り替え、手の真上に表示する。体験者が、交互に見える手を「自分の手」と感じるかどうかを体験してもらう。

- 比較対象は、他者の手の録画、または数フレーム前の自分の手（遅延自己映像）
- 他者側はその場で他者が動かす条件ではなく、**録画**である。ポスターと口頭で明示する
- 本機は**デモ用**であり、実験装置ではない。体験者の感想や記録は研究データとして扱わない

## 2. 前提と設計方針

| 項目 | 方針 | 理由 |
| --- | --- | --- |
| 使い方 | 体験者は立ったまま、発表者と話しながら使う | ポスター会場の動線 |
| 表示位置 | 表示を手の真上に重ねる（co-location） | 見えている手と実際の手の位置を一致させる |
| 他者映像 | 本機と同じ端末・同じ治具・同じ手袋で録画する | 照明・画角・歪みの差を手がかりとして残さない |
| ソフトウェア | HTML 1枚、外部ライブラリなし、サーバ処理なし | 配布・更新が容易。データが端末外に出ない |
| 優先度 | 製作期間（約3週間）に間に合うことを優先 | 大会日程 |

## 3. ハードウェア構成

### 3.1 構成

スマートフォンを画面を上にして手の甲の上に水平に保持し、背面カメラで真下の手を撮る。画面が手の真上に来るので、表示を手に重ねる配置が自動的に成立する。

| 部品 | 仕様 | 状態 |
| --- | --- | --- |
| スマートフォン | 背面に超広角カメラがある機種を推奨 | 機種未定 |
| 前腕カフ | 3Dプリント（PETG）、ベルクロで前腕に固定 | 未設計 |
| アーム・ホルダー | カフから手の甲の上へ伸ばし、スマホを水平に保持 | 未設計 |
| 遮光布 | 黒の薄布をスマホの周囲から垂らす | 未製作 |
| 手袋 | 白の綿手袋 S/M/L | 未購入 |

### 3.2 寸法の目安（推測：仕様値からの計算。実機未確認）

- カメラから手の甲までの高さ：超広角（対角約120°）で約6〜8 cm、広角のみの機種では約15〜20 cm
- 重量：スマホ約200 g＋治具約100 g
- スマホ画面（約150×70 mm）は手より小さい。実寸で表示すると手首側は映らない

### 3.3 端末別の注意

- 私の知る限り、iPad の多くの機種は背面に超広角カメラがなく、カメラが本体の角にある。前腕装着には向かず、机に置く使い方（付録A）に向く
- Mac は動作確認用。前面カメラのため、装置としては使わない

## 4. ソフトウェア仕様（index.html）

### 4.1 動作環境

- HTTPS または localhost で開く（ブラウザがカメラを許可する条件）
- 公開は GitHub Pages を想定（README 参照）
- 使用するブラウザAPI：`getUserMedia`、`MediaRecorder`、`canvas.captureStream`、`requestVideoFrameCallback`（非対応時は `requestAnimationFrame` で代替）、Web Audio、Screen Wake Lock（非対応時は無視）

### 4.2 画面構成

| 要素 | 内容 |
| --- | --- |
| 映像層（下から） | 代替画面「Other View」（他者映像が未設定のとき） → 他者録画 `<video>` → 遅延自己 `<canvas>` → ライブ自己 `<video>` |
| 操作パネル | 画面下部。上段（カメラ開始、表示モード、比較対象、使い方）を常に表示し、残りを4つのタブ（提示／他者映像／画面合わせ／記録・音）に分ける。遅延の設定は比較対象が遅延自己のときだけ表示。映像（パネル以外）のタップで表示・非表示。操作がないまま一定時間（5 / 10 / 30 s / しない、初期値5 s）たつと自動で隠れる。使い方の表示中は隠れない |
| 記録中表示 | 右上の赤い点 |
| 使い方 | パネルの「使い方」ボタンで全画面に重ねて表示 |

切替は、ライブ映像の層の表示・非表示で行う。比較対象は表示していない間も再生・更新を続けるので、表示したときに動きが途切れない。

### 4.3 表示モードとパラメータ

| 項目 | 値 | 初期値 |
| --- | --- | --- |
| モード | 自己 / 他者 / 交互 | 交互 |
| 比較対象 | 録画 / 遅延自己 | 録画 |
| 周期 | 100〜4000 ms（スライダ10 ms刻み、−／＋で10 ms） | 400 ms |
| 自己比率 | 0.05〜0.95（スライダ0.001刻み、−／＋で0.01） | 0.333（自己133 ms・比較267 ms） |
| 遅延 | 1〜60 フレーム | 10 |
| 倍率 | 0.5〜3 | 1 |
| 回転 | 0 / 90 / 180 / 270° | 0° |
| 左右反転・上下反転 | ON / OFF | OFF |
| クリック音 | ON / OFF、30〜120 BPM（1 kHz、約30 ms） | OFF、60 BPM |

周期と自己比率の初期値は Yokosaka et al. (2014) 実験1の切替条件（自己133 ms・他者267 ms、周期400 ms）による。同論文の補足資料では、比率が1:2に近いとき連続性の知覚が大きい傾向が報告されている。「Yokosaka 2014」ボタンでこの値に戻せる。60 Hz表示では133 msは8フレーム、267 msは16フレームに相当し、実際の表示はフレーム単位に丸められる。

交互モードでは、周期 T と自己比率 r に対し、経過時間 t の位相 φ = (t mod T) / T が φ < r のとき自己映像を表示する。

### 4.4 カメラ

- 要求値：1280×720、60 fps（理想値）。実際の値はパネル下部に表示
- 初回は背面カメラを希望として要求し、なければ利用可能なカメラを使う
- 許可後にカメラ一覧を表示し、超広角などを選べる（選べるかは端末依存、未確認）

### 4.5 遅延自己映像

- カメラの新しいフレームごとに、幅640 pxに縮小したコピーを61枚のリングバッファに保存する
- 表示は d フレーム前のコピー。ms表示は d / fps（カメラが報告したfps）による換算値
- 実際に見える遅延は、この値にカメラから表示までの遅延が加わる

### 4.6 録画・保存

**他者映像の録画**

- 「他者を録画」で開始・停止。停止すると比較対象に設定される
- 「録画を保存」で最後の録画を `other_hand_<日時>.mp4` / `.webm` として保存する
- 保存しない限り、録画はブラウザのメモリ上にしかなく、再読み込みで消える
- 「ファイル選択」で保存済みの動画を読み込める

**体験の記録**

- 「体験を記録」で開始、「記録停止」で終了し、2ファイルを保存する
- 動画 `session_<日時>.mp4` / `.webm`：画面に出ていた映像を、同じ変換（回転・反転・倍率、object-fit: cover相当）で録画用canvasに描き直したもの。長辺1280 px、画面と同じ縦横比、60 fps要求。パネル・ボタンは含まない
- 切替マーカー（選択式、初期値ON）：録画の左上24 px角に、自己表示中は白、比較対象表示中は黒の四角を描く。画面には出ない
- CSV `session_<日時>.csv`：表示ソースが変わった時刻ごとに1行

CSVの列：

| 列 | 内容 |
| --- | --- |
| t_ms | 記録開始からの時刻 [ms]（描画しようとした時刻） |
| shown | 表示したソース：self / rec / delay |
| mode | self / other / alt |
| src | rec / delay |
| period_s | 周期 [s] |
| self_ratio | 自己比率 |
| delay_frames | 遅延フレーム数 |
| flipH, flipV | 反転 |
| rot_deg | 回転 [°] |
| zoom | 倍率 |

### 4.7 保存先

保存はブラウザのダウンロード機能で行う。Macはダウンロードフォルダ、iPhone/iPadは「ファイル」アプリの「ダウンロード」。データが外部サーバに送られることはない。

## 5. 体験の流れ（1人 約1分）

1. 白手袋をはめ、前腕にデモ機を装着する
2. 自己のみ（約10秒）：映像と手が一致していることを確認する
3. クリック音をONにし、音に合わせて指を開閉してもらう
4. 交互・遅い周期（例 2 s）→ 速い周期（例 0.5 s）
5. 他者のみ（約5秒）で違いを確認する
6. 任意：比較対象を遅延自己映像に切り替え、遅延量を変えて比べる

周期・自己比率・遅延の初期値は、研究室内で試して決める（未確定）。

## 6. 制約・限界

- **提示タイミング**：切替は画面の更新（60 Hzで約16.7 ms）単位。ログの時刻は描画しようとした時刻で、画面に表示された時刻ではない。正確な値が必要な場合は、フォトダイオードやスロー撮影で実測する
- **記録の再構成**：体験記録の動画は画面キャプチャではなく描き直しである
- **遅延映像の画質**：幅640 pxに縮小するため、ライブ映像よりわずかに粗い。切替時の手がかりになる可能性がある
- **メモリ**：録画はメモリに貯めて停止時に保存する。数分以上の連続記録は端末によって不安定になる可能性がある（推測）
- **2つの映像の時間関係**：録画映像は体験者の動きと無関係に再生される。動きを揃えるにはクリック音のテンポに合わせて録画・体験する

## 8. 運用上の注意

- 体験者ごとに手袋を交換する
- 体験記録を残す場合は、体験前に一言断る。研究データとして使う場合は倫理審査の範囲を確認する
- 録画した動画やCSVは公開リポジトリに入れない
